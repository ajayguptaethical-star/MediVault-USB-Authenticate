Issue New USB Security Key

Generate a signed cryptographic token for your physical USB flash drive. Accessing highly sensitive patient records (such as HIV reports) requires this token.

How Hardware Security Works

  1. Copy the downloaded medsecure.medkey file to the root folder of any USB flash drive.
  2. Plug the USB drive into your workstation.
  3. Click "Authenticate Drive" in the USB Scanner.
  4. Once verified, your session has full clearance to preview and download confidential records.
